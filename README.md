# Kutscherhaus Pölitzstraße 12a · Web Portal (Desktop Version)

Architektur- und Immobilien-Website für das historische Baudenkmal **Kutscherhaus Pölitzstraße 12a** in Leipzig-Gohlis.

## Features
- **Desktop Landing Page**: Interaktiver Reveal-Slider, historische Chronik, Bento-Grid Raum-Galerie mit hochauflösendem Lightbox-Modal.
- **Interaktive Grundrisse**: Grundriss-Viewer mit Flächenaufstellung aller Ebenen.
- **Rechtliche Seiten**: Vollständiges Impressum (§ 5 DDG) und DSGVO-konforme Datenschutzerklärung.
- **Responsive Architecture**: Automatische Erkennung und Weiterleitung auf mobile Endgeräte.
